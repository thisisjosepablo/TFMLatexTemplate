# Contributing

Thank you for helping to improve this template! Issues and pull requests are
welcome, in English or in Spanish.

- **Bugs:** open an issue with the class options you used, the engine (pdfLaTeX
  or LuaLaTeX), your TeX distribution and year (or Overleaf), and the relevant
  part of `main.log`.
- **Your university's rules:** the best way to support a new university is a
  preset in [`presets/`](presets/README.md), based on its official regulations.
- **Changes to the class:** keep `tfmthesis.cls` university-independent, keep the
  defaults sensible for most Spanish universities, and check that every option
  combination still compiles (the GitHub Actions workflow does it for you on
  every pull request).
- **Language:** all the content of the template is written in British English.
