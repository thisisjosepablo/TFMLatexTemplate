\chapter{Supplementary Material}\label{app:supplementary}

\begin{guidance}
Appendices contain material that supports the thesis but would interrupt the reading of
the main text: additional tables and figures, questionnaires, consent forms, detailed
proofs, user manuals, extended code listings, etc. Appendices are numbered with letters
and referenced from the text like chapters, e.g.\ \autoref{app:sdg}. Single pages of a PDF
document can be inserted as figures with \texttt{\textbackslash includegraphics[page=2,
width=\textbackslash textwidth]\{file.pdf\}}.
\end{guidance}
