# Logos

Put the logo of your university (and optionally of your school or faculty) here,
preferably as a vector PDF, and set its path in `config.tex`:

```latex
\UniversityLogo{figures/logos/university-logo.pdf}
\SecondaryLogo{figures/logos/school-logo.pdf}
```

Download the logos from your university's corporate identity (*identidad
corporativa*) web page and follow its usage rules. While a file does not exist, a
neutral placeholder is drawn on the cover instead. No logos are distributed with
this template.
